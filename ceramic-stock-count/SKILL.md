# 陶瓷备货单统计

## 什么时候用

用户发来备货单、发货单、装箱单的图片或表格，要求统计数量、按品名汇总、核算套数与件数、生成 Excel 时。

## 统计口径（固定，不要每次重新问）

1. **套数**：按单据上标注的"套"或"件/套"换算，不自行假设。
2. **件数**：单个器物的实际个数，等于套数乘以每套件数。
3. **分组维度**：品名 → 尺寸 → 批次，三层。尺寸必须单独列出，不能合并。
4. **剔除规则**：用户指定剔除某批次（如"排除 10/27"）时，先剔除再统计，并在结果里注明剔除了哪一批、剔除多少。
5. **读图分歧**：图片模糊或尺寸看不准时，**如实标注"读图存疑"**，不猜、不四舍五入填补。列一行"待人工确认"清单。

## 执行步骤

1. 读图或读表，逐行提取：品名、尺寸、数量、单位、批次。
2. 逐行核对单位是"套"还是"个"，单位不明就标存疑。
3. 按品名 → 尺寸汇总，算出套数小计和件数小计。
4. 输出两个表：明细表（原始行）、汇总表（分品名套数与件数）。
5. 生成 Excel 到桌面成品文件夹，回读核对总量是否与明细合计一致。

## 输出要求

- Excel 至少两个 sheet：`明细`、`汇总`。
- 汇总表列：品名、尺寸、套数、件数、备注。
- 文件命名：`陶瓷统计_YYYYMMDD.xlsx`。
- 交付时说明：总套数、总件数、剔除的批次、存疑行数。

## 禁止

- 不猜尺寸。看不清就标存疑。
- 不把不同尺寸合并成一行。
- 不在用户没要求时删除任何原始行。
